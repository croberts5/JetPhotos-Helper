JetPhotos Helper

Features

Checks whether the user has accepted photos with the provided registration.
Returns the most recent photo taken date for the provided registration.
Automatically suggests the ICAO equivalent when an IATA airport code is entered.
Reads the GPS EXIF data from uploaded photo and matches the nearest airport's ICAO code.

Interface Tweaks

Allows inputting the photo date as a string (MM/DD/YYYY) instead of being forced to use the date picker.
Hides the submission guidelines text found on the left-hand side of the upload page.
Converts UTC timestamps on the page to your local time zone.
Shows the registration and serial number check section below the upload button.
