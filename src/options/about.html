JetPhotos Helper

Less "Bad info" more "Too much or too little contrast"

Features

  • Registration & date lookup on auto-fill
  • Manual date text entry
  • Hide submission guidelines
  • Support for automatically swapping a provided IATA airport code for its ICAO equivalent
  • Nearest airport from photo GPS coordinates
  • Offline tools: centering lines, horizon grid overlay, equalization, histogram preview

Bug Fixes

  • Input fields automatically trimmed of leading/trailing spaces
  • Serial number preserved when registration has no auto-fill match
  • Registration auto-populated in form when not found in auto-fill database
